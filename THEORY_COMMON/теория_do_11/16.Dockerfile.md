### 🔍 Что интересного в этих Dockerfile?

**1. Database (PostgreSQL)** — простой и понятный:
```dockerfile
FROM postgres:14-alpine  # ← лёгкий образ на Alpine Linux
# ... переменные окружения ...
COPY init.sql /docker-entrypoint-initdb.d/  # ← авто-инициализация БД
HEALTHCHECK ...  # ← проверка здоровья контейнера
```

**2. Остальные 7 сервисов (Java-приложения)** — используют **многостадийную сборку** (multi-stage build):
```dockerfile
# Стадия 1: Сборка (builder)
FROM maven:3.9-eclipse-temurin-11 AS builder
# ... скачивание зависимостей, компиляция ...
RUN mvn package -DskipTests

# Стадия 2: Запуск (runtime)
FROM eclipse-temurin:8-jre-alpine  # ← только JRE, без компилятора!
# ... копирование готового JAR из builder ...
COPY --from=builder /app/target/*.jar app.jar
ENTRYPOINT ["java", "-jar", "app.jar"]
```

> 💡 **Зачем так сложно?** Чтобы итоговый образ был **меньше и безопаснее**: в финальный образ попадает только скомпилированный `.jar` и минимальная Java-среда (JRE), а Maven, исходный код и кэш зависимостей остаются в «промежуточной» стадии и не попадают в продакшен.

### 🧠 Коротко для запоминания

```
🔹 Всего: 8 Dockerfile (1 БД + 7 микросервисов)
🔹 База данных: простой образ postgres с init-скриптами
🔹 Микросервисы: многостадийная сборка (Maven → JRE) для минимизации размера
🔹 Все образы основаны на Alpine — это делает их легче (~5 МБ вместо ~500 МБ)
🔹 Везде есть HEALTHCHECK или готовые скрипты проверки готовности
```

### 💡 Совет для проекта

Когда будешь создавать манифесты Kubernetes для этих сервисов:

1.  **Для database**: используй `StatefulSet` (а не Deployment), потому что базе данных нужно постоянное имя и стабильное хранилище (PV).
2.  **Для Java-сервисов**: можно использовать обычный `Deployment`, но добавь `readinessProbe` и `livenessProbe`, чтобы Kubernetes понимал, когда приложение реально готово принимать трафик (особенно важно, так как Java-приложения долго стартуют).
3.  **Порты**: обрати внимание, что у каждого сервиса свой порт (8080, 8081, 8084...), чтобы не было конфликтов в Kubernetes Service.

Если нужно — помогу составить шаблон `Deployment.yaml` для любого из этих сервисов. 🚀
